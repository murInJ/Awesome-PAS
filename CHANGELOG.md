# Changelog

## 0.2.0 — 2026-07-19

- Rebuilt the bilingual website into four explicit areas: methods, datasets, benchmarks, and statistics/trends.
- Ordered methods, datasets and benchmark protocols by year and rendered detailed resource cards from Markdown.
- Added fixed repository and GitHub Pages links for `murInJ/Awesome-PAS`.
- Removed repository-setup, data-model and local-preview sections from the public README files.
- Added end-to-end data integration validation for Markdown parsing and deduplication.

## 0.1.1 — 2026-07-19

- Fixed the first-deployment failure when GitHub Pages has not yet been enabled.
- Added an explicit Pages preflight check and actionable error message.
- Added optional automatic Pages enablement through the `PAGES_PAT` secret.
- Upgraded GitHub-maintained Actions to Node.js 24-compatible major versions and replaced the Node 20-based Pages artifact wrapper with a Node 24 upload step.
- Added bilingual GitHub Pages deployment documentation.

- Initial bilingual repository structure.
- Physical presentation attack, digital attack, physiological liveness and attack-generation collections.
- Initial dataset and benchmark pages.
